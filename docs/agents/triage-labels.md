# Triage Labels

Use these strings in local issue files' `Status:` lines.

| Canonical role | Tracker string | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | Waiting on reporter information |
| ready-for-agent | ready-for-agent | Fully specified; ready for an AFK agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

When a skill mentions a triage role, use its tracker string.
Edit the tracker column to change the vocabulary.
